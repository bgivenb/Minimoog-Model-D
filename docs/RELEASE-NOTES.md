# Model D 1970 v1.0.0

Created by **Given Peace**. Personal-use Minimoog Model D-inspired instrument built with JUCE 8.0.15.

The Windows x64 download includes the VST3 bundle, standalone app, panel preview, 15-second audio demo and setup instructions. Ableton identifies the plugin as **Model D 1970** under manufacturer **Given Peace**.

Copy the complete `Model D 1970.vst3` folder to `C:\Program Files\Common Files\VST3`, accept the administrator prompt, enable VST3 system folders in Live, and rescan. This is a digital approximation, not a circuit-exact emulation.

Validation: the compiled VST3 passed scan/load, MIDI timing, sustain/release, tuning, lowest-note priority, held-note fallback, pitch bend, state recall, malformed-state handling, all five presets at three sample rates and four buffer sizes, randomized parameter stability, and editor creation/resizing. The panel was visually inspected. Playback inside Ableton Live has not yet been verified.
